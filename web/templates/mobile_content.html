Penyebab Konten Baru Belum Tampil di Mobile: Supabase Row Level Security (RLS)
RLS Policy Membatasi Anon Write

Saat Anda menambah tips atau panduan baru, data tersimpan di sistem lokal Web Admin. Namun database Supabase menolak penyimpanan cloud dengan pesan: new row violates row-level security policy karena role public anon hanya diberi izin baca (SELECT). Akibatnya, aplikasi mobile yang membaca data dari Supabase belum dapat melihatnya.

-- Buka Supabase Dashboard > SQL Editor > Tempel & Klik RUN:
-- Nonaktifkan RLS agar Web Admin & Mobile dapat mengelola konten:
ALTER TABLE public.literacy_tips DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.guide_principles DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.guide_contents DISABLE ROW LEVEL SECURITY;
ALTER TABLE public.app_info DISABLE ROW LEVEL SECURITY;

-- Atau jika ingin tetap aktifkan RLS dengan izin penuh:
DROP POLICY IF EXISTS "Admin full access for literacy_tips" ON public.literacy_tips;
CREATE POLICY "Admin full access for literacy_tips" ON public.literacy_tips FOR ALL USING (true) WITH CHECK (true);
DROP POLICY IF EXISTS "Admin full access for guide_principles" ON public.guide_principles;
CREATE POLICY "Admin full access for guide_principles" ON public.guide_principles FOR ALL USING (true) WITH CHECK (true);
DROP POLICY IF EXISTS "Admin full access for guide_contents" ON public.guide_contents;
CREATE POLICY "Admin full access for guide_contents" ON public.guide_contents FOR ALL USING (true) WITH CHECK (true);
DROP POLICY IF EXISTS "Admin full access for app_info" ON public.app_info;
CREATE POLICY "Admin full access for app_info" ON public.app_info FOR ALL USING (true) WITH CHECK (true);
