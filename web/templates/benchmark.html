Analisis Ilmiah Mengapa Bernoulli NB Unggul

1. Karakteristik Disinformasi Berbahasa Indonesia:

Ciri utama hoaks terletak pada keberadaan kata-kata pemicu biner (seperti: "viralkan", "sebarkan", "jangan dihapus", "cair serentak"). Model Bernoulli hanya menghitung apakah kata itu ada (1) atau tidak (0), sehingga sinyal hoaks langsung tertangkap kuat tanpa peduli berapa kali kata itu diulang.

2. Latensi Instan Sangat Cocok untuk Mobile API:

Dengan waktu inferensi 7 milidetik dan ukuran RAM hanya 0.39 MB, Bernoulli NB dapat dijalankan ribuan kali per detik tanpa membebani server backend aplikasi mobile Flutter.

K-Means dengan max_features = 1.000 Paling Optimal:

  • 1.000 Kata: Silhouette Score 0.0524 (🏆 Klaster terpisah paling rapi).
